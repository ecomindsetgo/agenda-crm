# Psicología Pro V3.3 — Presentación, Finanzas y Formularios

## Cambios aplicados

- Mejora visual del módulo **Finanzas**:
  - cabecera más clara y ejecutiva;
  - botones de exportación y reporte más consistentes;
  - tarjetas superiores con iconografía;
  - bloques con títulos sin emojis heredados;
  - tablas y etiquetas con mejor jerarquía visual.

- Limpieza del módulo **Documentos**:
  - se eliminó la leyenda **"Expediente digital"**;
  - la explicación de documentos queda solo dentro del módulo Documentos;
  - se evita mostrar ese texto en otras ventanas.

- Mejora de fichas / modales:
  - **Registrar / editar cita**;
  - **Registrar / editar paciente**;
  - **Mi cuenta**;
  - **Centro de reportes**.

- Unificación visual del sistema:
  - títulos con iconografía más profesional;
  - formularios en bloques tipo ficha;
  - menos emojis heredados;
  - colores más cálidos y clínicos;
  - mejor consistencia general.

## Compatibilidad

Se conserva la misma estructura de Firebase y los mismos registros existentes de pacientes, citas, historias y notas.
